# Iron Man (2008)

*Iron Man* is the 2008 superhero film that launched the **Marvel Cinematic Universe (MCU)**. Directed by Jon Favreau, it follows billionaire inventor Tony Stark as he builds a powered suit of armor to escape captivity and become a hero.

| Detail | Info |
| :--- | :--- |
| **Director** | Jon Favreau |
| **Starring** | Robert Downey Jr., Gwyneth Paltrow, Jeff Bridges |
| **Release Year** | 2008 |

## Highlights

* **Iconic Casting:** Robert Downey Jr. defined the tone and humor of the MCU.
* **Visual Effects:** Blended practical mechanical suits with seamless CGI.
